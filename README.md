# SOC Analyst Portfolio

Repositorio de mi formación autodidacta como SOC Analyst — un programa equivalente a máster, de 8-10 meses, siguiendo una metodología basada en incidentes reales.

## Sobre mí
Carlos — en formación activa hacia un puesto de SOC Analyst Tier 1/2.

## Qué vas a encontrar aquí

- **`lab/`** — arquitectura y evolución de mi laboratorio (topología de red, herramientas desplegadas, capturas).
- **`writeups/`** — informes de investigación de incidentes, casos prácticos y triages, uno por caso.
- **`detections/`** — reglas de detección que he escrito (Sigma, Wazuh, Sentinel/KQL).
- **`threat-intel/`** — IOC recopilados, notas de MITRE ATT&CK, perfiles de amenaza.
- **`scripts/`** — automatización en Python y PowerShell orientada a Blue Team (enriquecimiento de IOC, parsers de logs, generación de informes).
- **`dashboards/`** — capturas y exports de dashboards (Kibana, Sentinel).
- **`projects/`** — un proyecto por módulo del programa.
- **`final-project/`** — proyecto final: una semana como único analista SOC de una empresa ficticia.
